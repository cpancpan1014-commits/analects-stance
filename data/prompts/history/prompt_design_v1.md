# 训释对象词抽取 · 提示词规范 v1

> 用途：从五层《论语》注本中抽取「注家在解释哪个词、给出什么训释」，
> 用于构建「词 × 注家」的注释论争网络。
> 目标模型：DeepSeek（deepseek-chat），OpenAI 兼容接口。

## 一、任务定义

给定**一章**《论语》原文与**一家**注文，输出该注家在本章中实际训释的词条列表。
一条记录 = 一个被训释词 + 该注家给出的训释 + 训释类型 + 原文依据片段。

## 二、输出格式（严格 JSON，无 markdown 围栏）

```json
{
  "chapter": "01-01",
  "annotator": "zhuxi",
  "items": [
    {
      "term": "學",
      "gloss": "效也；後覺者效先覺之所為",
      "type": "字義",
      "evidence": "學之為言效也"
    }
  ]
}
```

字段约束：

| 字段 | 约束 |
|---|---|
| `term` | **必须是原文中实际出现的字或词**，1–4 字，用原文写法（繁体）。若注家训释的是原文中不存在的字（纯引申），填 `null` 并跳过 |
| `gloss` | 该注家给出的训释，压到 30 字以内，保留其术语 |
| `type` | 四选一：`字義`（训诂，某字=某义）／`句意`（串讲整句）／`義理`（引申为哲学命题）／`名物`（人物、制度、器物考证） |
| `evidence` | 注文中支撑该条的最短原文片段，≤25 字，须逐字照录 |

## 三、边界规则（必须遵守）

1. **只抽本章原文范围内的词**。注家引他章、引《诗》《书》而作的解释，若未落回本章原文，丢弃。
2. **引述他人注不算本人训释**。朱熹引「程子曰」、邢昺引「馬曰」，若本人未加评断，不记为朱熹／邢昺的训释；若本人有「愚謂」「非也」等评断，则记入并保留评断语。
3. **邢昺疏的特殊体裁**：`○注「馬曰子者」至「說懌」` 这类是**标出被疏注文的范围**，不是训释对象。此类标题行全部丢弃，只抽「正義曰」之后的实质训释。
4. **同一 term 可有多条**（如仁斋「學，做也，覺也」是两个义），但须合并为一条 `gloss`，用「；」分隔，不拆成两条。
5. **不为求全而臆造**。注家未训的词不补。宁可少，不可编。
6. 原文为繁体，`term` 一律用繁体；`gloss` 与 `evidence` 照录原文，不改简体。

## 四、已知陷阱

| 陷阱 | 表现 | 处理 |
|---|---|---|
| 页眉残留 | 文本中 `12論語古義論語徵`、`卷一13` | 已在清洗阶段删除；若仍见，忽略 |
| 注音 | `說、悅同`、`慍，紆問反` | 属字義类，保留；`紆問反` 这类反切计入 gloss |
| 圈号 | `◯`、`○` 分隔符 | 仅作分条标记，不入 gloss |
| 徂徕体例 | 长段落论辩，训释散落其中 | 逐句扫，不因段落长而漏 |

## 六、这一组示例已经暴露的分歧

「學」一字：

| 注家 | 训释 | 类型 |
|---|---|---|
| 朱熹 | 效也（后觉效先觉） | 字義 |
| 仁斋 | 做也，覺也 | 字義 |
| 徂徕 | 學先王之道也 | 義理 |

朱熹的「效」是**认识论**（模仿先觉者）；仁斋的「覺」是**心性论**（觉悟）；徂徕的「先王之道」是**制度论**（学的是先王留下的礼乐制度）。
三个训释指向三种完全不兼容的教育哲学——这正是「训释对象词」网络要捕捉的东西：**同一字位上的三种教育学**。
